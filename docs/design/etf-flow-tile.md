## 立场与方案卡
- **立场**：顺手（扩展现有卡片）。专用立场（独立页）对"扫一眼"过度建设；自动只做一半：头部信号计数（系统替你数几只动了），不做预测性判断。
- **入口**：大盘预览页底部行，原「权重ETF」卡原位升级。
- **步骤**：打开 dashboard → 目光落到底部行 → 读完。
- **修了什么**：做决定的地方没有做决定要用的信息（价格有、份额没有）。
- **拿到什么**：8 只宽基 ETF 每行 = 名称+代码 | 现价/涨跌 | 份额变动%（季频口径） | 成交放大倍数 | 信号；头部 = 信号 n/8 · 份额截至 {date}（季频）。
- **值得**：现在不用再离开 dashboard 去别处查份额。
- **出错时**：/api/finance/etf-flow 失败 → 卡片退回旧版纯价格行（快照数据），份额列显示"未同步"，不报整卡错误。
- **赌注**：用户每天看 dashboard，ETF 卡已在视线里。
- **放弃什么**：历史趋势图、披露持仓明细（预留一行"汇金披露持仓"，B 线数据通了再亮）。

## 视觉沿用清单（不许新造）
- 卡片骨架 `md-tile` / `md-tile__title` / `md-tile__caption`，入场延迟 `--d` 沿用 540ms 档位。
- 数字用 `md-num`；涨跌着色用现有 `trendClass`；字号用 `--app-text-sm` 等现有变量。
- 行结构沿用 `md-etf-row`；新列（份额变动/倍数/信号）复用同一行网格，信号用小型圆点+文字，不引入新组件库元件。
- 数据：`/api/finance/etf-flow`（python-service 直连，已白名单）；失败回退到 snapshot 的 4 只纯价格行。
- i18n：5 个语言包 key 同步（审计测试要求 key 集一致）。
