# 大盘预览大屏 · 设计说明

意图：**存量项目加新页面**（视觉沿用现有系统，不走方向探索）。阶段：静态高保真小样（Q1=C），确认后交实施。

## 用户任务

用户是谁，来做什么，拿到什么：**重度盯盘的个人投资者，开始对话前想扫一眼今天市场和自己票的情况**——在 chat 空态工作台点「大盘预览」，一屏看完指数走势、自选股、权重 ETF、涨跌停情绪和龙虎榜，回去继续干活。不做交易、不做深度分析，深度分析回 chat 里问 agent。

## 三问（品类 / 首屏主角 / 同类标杆）

- **品类**：金融数据仪表盘（dashboard），但寄居在一个「午后的工作室」气质的暖纸 RAG 应用里。
- **首屏主角**：四大指数走势（用户说的「A股走势」是一级信息），其余五格都是它的陪衬。页面上只有一个主角。
- **同类标杆**：Bloomberg/同花顺 PC 终端走深色高密信息流；开盘啦/雪球做卡片化。本产品是暖纸 + 珊瑚 + 衬线问候语的工作台，大屏若突然切成终端黑，等于另一个产品。方向由此推出——

## 选定方向：「晨间行情桌」

把金融版大报的版式铺在暖纸桌面上：**Noto Serif SC 衬线做格标题和大数字标题，JetBrains Mono 等宽做全部行情数字，珊瑚橙只做状态与焦点，红涨绿跌（A股惯例）做唯一的语义色对**。记忆点有两个：

1. 暖纸底 + 衬线标题的金融仪表盘（同类清一色终端黑，这一眼就认得出是谁家）；
2. 指数格的「当日快照条」——一根低—高区间轨道上标今开刻度和最新点，不用分时数据也能读出日内位置。

视觉变量全部映射自 `frontend/src/assets/theme/theme.css`（light/dark 双套），涨跌色映射自 `finance/components/kline/palette.ts`。实现时不新增设计变量。

## 信息架构（1440×900 一屏，bento 12 列）

```
┌ 顶栏：返回 · 衬线标题「大盘预览」· 日期 ｜ 数据时间 · 状态chip · 主题 · 刷新 ┐
├ 指数快照条：上证50 / 科创50 / 北证50 / 中证500 / 中证1000（ticker chips） ┤
├ 四大指数走势 2×2（8列）                    ├ 市场情绪（4列）      ┤
│  上证 / 深成 / 创业板 / 沪深300             │ 涨停 跌停 炸板 最高连板 │
│  60日折线 + 当日快照条                      │ 涨跌家数条            │
├ 自选股（5列）        ├ 龙虎榜（4列）      ├ 权重ETF（3列）       ┤
│ 7行：价/涨跌/spark/状态 │ 净买入前5+机构净额 │ 6只宽基紧凑行        │
└──────────────────────────────────────────────────────────────┘
```

## 关键状态

- `?state=open` 盘中（chip 珊瑚脉冲点，快照条标「最新」）/ `?state=closed` 盘后（标「收盘」）/ `?state=holiday` 非交易日（chip 灰，数据时间为最近交易日）
- `?watchlist=empty` 自选股空态（引导去自选页添加，不放插画）
- `?theme=dark` 深色（沿用 theme.css dark 变量）
- 加载骨架不在小样范围，实现时沿用各格标题 + 骨架屏即可

## 三处基本动效（呼应 workbench 现有 motion）

1. **主操作反馈**：入口卡片 hover 抬起 -2px + 暖光阴影、按下 scale(0.98)（与 recent-card 完全一致）
2. **状态切换**：刷新 → 图标旋转、数据时间更新、全屏数字 300ms 透明度起伏一次
3. **首次进入**：各格从下方 12px 依次浮起（stagger 60ms，与 workbench `data-rise` 同源）；`prefers-reduced-motion` 时全部关闭

## 数据口径（实施时对照）

| 格 | 数据源 | 现状 |
| --- | --- | --- |
| 指数 60日折线 | python-service `GET /api/kline`（.TI 指数已支持） | 现成 |
| 指数/ETF 快照 | `index.v_index_latest` / `fund.v_etf_latest` | **需新接口**（`/api/quotes` 拒 .TI） |
| 自选股 | Go `GET /api/v1/watchlist` + `/api/quotes` 批量 | 现成 |
| 涨跌停/炸板/连板 | `special.v_limit_*_pool` COUNT | **需新接口** |
| 龙虎榜 | `special.v_dragon_tiger` 按净买排序 | **需新接口** |
| 涨跌家数条 | 全市场聚合 | **偏重，可砍**；砍掉后情绪格四数字仍成立 |
| 日内分时 | 本地无股票分钟线（仅期货有） | 不做，用 60日折线 + 快照条替代 |

样稿中全部数字为模拟数据（界面内不标注），曲线为确定性随机游走。

## 验收重点

- 一屏 1440×900 无滚动；1366×768 不挤压变形（小视口自选股减到 6 行、各处 padding 收紧）
- 中文标点在衬线标题下不溢出； mono 数字 `tabular-nums` 不对齐跳动
- 红涨绿跌在浅/深两底上都过 4.5:1；**深底下红绿各提一档（#f87171 / #34d399）**——palette.ts 的深色值是在 K 线画布 #181d26 上测的，本页容器是更亮更暖的 #2A231C，原值掉档，这是有意的偏离
- 空态/盘后/非交易日三状态文字不折行溢出

## 评审记录（独立评审，无制作上下文的评审者）

- **Round 1：7/10。** 最大差距：情绪格 40% 死白；指数卡无参照系；快照条层级塌陷；「炸板 率 23.6%」语义断裂；空态浪费首屏黄金位；深色红绿未独立调色。硬伤：小视口贴边、「6板」字号差、平盘 legend 误读、龙虎榜枚举值直出。
- **Round 2：8.5/10。** ①③④⑤⑥ 验收通过；② 部分（60 日图仍无 Y 参照）；新指出 lu5 柱状与涨跌条粘连、图例行 9px 低于可读底线。已全部修掉：60 日图加昨收水平虚线、炸板改「21 只 · 23.6%」、柱状图加基线和间距、图例行 10.5px。
- 评审者结论：**可以走实现**。第三轮未跑——第二轮剩余项全是局部精修且已闭环，边际收益低。
