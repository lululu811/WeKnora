# Z哥 吐槽卡

Z哥（`builtin-zettaranc`）的人工反馈记录。**这里记的是「它本该做 X，实际做了 Y」**——
只有能对应到 prompt 或知识库某处改动的反馈才算信号，对应不上的只是情绪。

## 怎么用

遇到不满，**直接在对话里跟我说一句**就行，例如：

> 刚才问茅台能不能买，它拆成五个工具调了三次还没给完整诊断

结构化是我的活儿，我会把它整理成下面这个结构追加进来。你只管把「本该」和「实际」说具体。

## 判据

一条反馈要能回答：**你能不能指着 prompt 的某一行说「改成这样这条就消了」？**

- 能 → 有效反馈
- 不能 → 补具体点再来（哪个工具不对？该给什么价位？哪句自相矛盾？）

## 状态

- `待处理` —— 已记录，尚未改
- `已修` —— prompt/知识库已改，等验证
- `已验证` —— 用该条场景重跑，问题消失
- `已驳回` —— 判定不成立（如工具行为符合预期、反馈有误）
